# IKEA Web Application - Cucumber Automation

This repository contains my Selenium automation project for testing the **IKEA Egypt website**.

The project was built using **Java, Selenium WebDriver, Cucumber, and TestNG**.

## What I Tested

The automated tests cover:

* User registration
* Duplicate email registration
* User login
* Invalid login
* Product search
* Product details
* Shopping cart
* Favourites
* Checkout and payment validation

## Test Scenarios

A total of **9 scenarios** were automated, covering user authentication, product search, product details, shopping cart, favourites, and checkout.

## Tools

* Java
* Selenium WebDriver
* Cucumber
* TestNG
* Maven
* Page Object Model (POM)
* ChromeDriver
